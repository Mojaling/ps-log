순위팀원점수연속오늘

팀원의 문제

    아직 참가한 팀원이 없습니다.

    설정

    화면

    밝은 모니터에서 배경·카드·입력 영역의 경계가 흐리면 “선명하게”를 선택하세요. 이 설정은 동기화되지 않고 현재 브라우저에만 저장됩니다.

    깃허브 동기화

    기록은 비공개 저장소의 data.json에 저장됩니다. 토큰은 현재 탭 세션에만 보관되며 탭 세션이 끝나면 다시 입력해야 합니다.

    복습 알림 이메일

    받는 주소는 브라우저나 URL에 저장하지 않습니다. Cloudflare Worker의 암호화된 MAIL_TO 시크릿으로만 설정하며 “메일로 정리 보내기”와 자동 발송이 같은 주소를 사용합니다.

    복습 일정

    쉼표로 구분해 1~365일 사이에서 설정합니다. 예: 5, 5, 10, 5, 10, 25, 30. 변경한 값은 새로 실패로 기록하는 문제부터 적용되며 기존 문제의 복습 이력은 유지됩니다.

    개념 편집기

    개념 Markdown 편집창에서 Tab을 누르면 지정한 칸만큼 공백을 넣고, Shift+Tab을 누르면 들여쓰기를 제거합니다.

    팀 랭킹

    팀 서버가 설정된 배포에서만 동작합니다. 처음 참가할 때 팀장이 만든 일회용 초대 코드가 필요합니다.

    사용량

    data.json 예상 크기와 사진 용량은 설정창을 열면 바로 계산됩니다. 아래 버튼을 누르면 GitHub에 실제 저장된 파일 크기와 API 잔여 요청도 함께 확인합니다. Cloudflare 요청 수는 이 사이트를 띄우는 Worker를 통해 조회하며 관리 키(CRON_KEY)가 필요합니다. 비워 두면 그 항목만 건너뜁니다. 이 키도 현재 탭 세션에만 보관됩니다. Resend 발송량은 대시보드 링크로 안내합니다.
