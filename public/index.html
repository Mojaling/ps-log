설정

깃허브 동기화

기록은 비공개 저장소의 data.json에 저장됩니다. 토큰은 이 브라우저에만 저장되고 사이트에는 올라가지 않습니다. 기기마다 한 번씩 입력하세요.

복습 알림 이메일

여기 저장한 주소로 "메일로 정리 보내기" 버튼이 복습 목록을 채워 보냅니다. 날짜마다 자동 발송은 Worker가 맡습니다 (README의 Cloudflare 배포 항목 참고).

개념 편집기

개념 Markdown 편집창에서 Tab을 누르면 지정한 칸만큼 공백을 넣고, Shift+Tab을 누르면 들여쓰기를 제거합니다.

사용량

깃허브 API 잔여 요청은 위에 넣은 토큰으로 바로 확인합니다. Cloudflare 요청 수는 이 사이트를 띄우는 Worker를 통해 조회하며 관리 키(CRON_KEY)가 필요합니다. 비워 두면 그 항목만 건너뜁니다. 이 키도 이 브라우저에만 저장됩니다. Resend 발송량은 대시보드 링크로 안내합니다.
